# Ultimate Macro

The private GitHub repository for this project is [adrianmue/UltimateMacro](https://github.com/adrianmue/UltimateMacro). Its default branch is `main`.

When completing project changes for the user, check the repository for updates, publish the verified changes there, and confirm the remote commit before reporting completion. Track the source, example macros under `Examples/`, build configuration, and documentation. Keep personal macro recordings, machine-local settings, shortcuts, and generated build and release files local.
