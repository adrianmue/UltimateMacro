# Ultimate Macro

The GitHub repository for this project is [adrianmue/UltimateMacro](https://github.com/adrianmue/UltimateMacro). Its default branch is `main`.

When completing project changes for the user, check the repository for updates, publish the verified changes there, and confirm the remote commit before reporting completion. Preserve any existing repository changes and follow its branch protections. If this folder has no authenticated Git checkout, use the GitHub connector.

Track the source, example macros under `Examples/`, build configuration, and documentation. Keep personal macro recordings, machine-local settings, shortcuts, and generated files out of Git. Distribute the portable Windows ZIP through GitHub Releases. Increment the project version for an updated Windows build and verify that the release workflow publishes the matching ZIP.
